# CIS 2368 Final Project – Sprint 1  
**Author:** Temi Ilori  

### Description  
Recipe Manager API that tracks ingredients, recipes, and updates inventory when cooking.

### Endpoints
- `/` – confirms API running  
- `/ingredients` – shows all ingredients  
- `/recipes` – shows all recipes  
- `/cook` – deducts ingredient amounts for a given recipe  

### Database
Uses MySQL with `recipe`, `ingredient`, and `recipeingredient` tables.  

### Tech Stack
Flask 3.1.3 • MySQL Connector 9.0.0 • Python 3.9.6
